# 전시 팜플렛 프로젝트

이 프로젝트는 단일 HTML 파일로 구성되었던 전시 슬라이드 덱을 Vite 기반의 현대적인 웹 프로젝트 구조로 리팩토링하고, 성능 및 사용자 경험(UX)을 극대화한 결과물입니다.

## 1. 프로젝트 구조 (Architecture)

관심사 분리(Separation of Concerns) 원칙에 따라 파일을 모듈화했습니다.

- **`index.html`**: 메인 엔트리 포인트. 각 슬라이드를 주입하기 위한 `<!--#include file="..."-->` 태그를 포함합니다.
- **`src/style.css`**: 프로젝트의 모든 스타일을 관리합니다. 인라인 스타일을 배제하고 클래스 기반으로 정의되어 있습니다.
- **`src/main.js`**: 슬라이드 전환, 이미지 뷰어, 자동 숨김 컨트롤 등 모든 동적 로직을 담당합니다.
- **`src/slides/`**: 슬라이드별 개별 HTML 조각 파일들 (01~06).
- **`public/`**: 모든 원본 이미지 파일들이 위치합니다. 빌드 시 `dist/` 폴더로 자동 복사됩니다.
- **`vite.config.js`**: 빌드 설정 파일. HTML 인클루드 플러그인, 단일 파일 번들링, 이미지 최적화 설정이 포함되어 있습니다.

## 2. 주요 최적화 사항 (Performance)

- **이미지 자동 압축**: `vite-plugin-image-optimizer`를 통해 빌드 시 이미지 용량을 약 35% 절감했습니다.
- **지능형 지연 로딩 (Lazy Loading)**: 슬라이드 2~6의 이미지는 `data-src` 속성을 사용하여 초기 로딩 속도를 높였습니다.
- **인접 슬라이드 프리로딩 (Preloading)**: 사용자가 현재 보고 있는 슬라이드의 앞/뒤 이미지만 미리 백그라운드에서 로드하여 끊김 없는 관람 환경을 제공합니다. (중복 로드 방지 로직 포함)

## 3. 핵심 기능 및 UX (Features)

- **인터랙티브 뷰어**: 작품 클릭 시 확대되며, 데스크탑(Esc 키) 및 모바일(뒤로가기 버튼) 대응이 완벽하게 구현되어 있습니다.
- **스마트 컨트롤러**: 내비게이션 버튼과 카운터는 조작 시에만 나타나며, 3초간 입력이 없으면 자동으로 숨겨집니다. 조작 중에는 타이머가 자동으로 갱신됩니다.
- **단일 파일 빌드**: 모든 결과물은 외부 의존성 없는 하나의 HTML 파일(`dist/index.html`)과 이미지 자산들로 빌드되어 배포가 매우 간편합니다.

## 4. 작업 가이드 (For Future Sessions)

- **수정**: `src/` 폴더 내의 각 파일(HTML, CSS, JS)을 수정합니다.
- **이미지 추가**: 새로운 이미지는 `public/` 폴더에 넣고 슬라이드 HTML에서 파일명으로 참조합니다. (지연 로딩을 위해 `data-src` 권장)
- **빌드**: 모든 수정 후 `npx vite build`를 실행하여 `dist/index.html`을 갱신합니다.
